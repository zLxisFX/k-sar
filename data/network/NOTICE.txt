The complete imported routable database is graph.json.gz in this directory.
roads-display.geojson is a simplified display derivative; it is not the graph.

Source: the existing K-SAR research workspace, extracted with OSMnx/Overpass.
The graph has 62,446 nodes and 155,830 directed multiedges. The 215 hospital-tagged
OSM features are representative map anchors, not a verified count of distinct
operational hospitals. Some features can refer to the same facility. Capacity,
opening status, emergency capability and actual entrances are unknown.

The graph is a 2026 extract, not a July 2024 historical snapshot. Import preserves
full source edge lengths and geometry. manifest.json records original input
hashes, import hashes, schema, processing and an externally observed HTTP date.
Source timestamp fields are retained without asserting their host-clock accuracy.

Elevation values are the minimum sampled DSM surface height along each edge:
all original geometry vertices plus samples at <=15 projected metres in EPSG:3857.
Heights use metres EGM2008. DSM includes objects such as buildings and vegetation;
these values are not surveyed road-deck elevations. Six directed edges have
partial missing/outside coverage and are conservatively excluded in scenarios,
separately from known samples exceeding the assumed 0.30 m depth threshold.

Uniform water surface and uniform lowering are scenario assumptions. There is
no hydraulic model, bridge clearance, road-deck survey, traffic, drainage or
field validation. Network paths are not certified evacuation instructions.
